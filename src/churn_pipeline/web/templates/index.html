AI final project · CrewAI flow with a data contract

A churn pipeline that refuses to run on bad data

AI agents predict which customers are about to leave (churn). Checks written in plain code compare every dataset with an agreed contract, and the pipeline stops, with an explanation, when something changes.

Why: at Harbor & Vale, an upstream export silently switched a field from cents to dollars. The model kept running and ranked customers almost at random for five weeks. This is the pipeline that would have caught it.

Words you will see

Plain-English meanings, in case the data-science terms are new.

Churn
A customer who stops buying and leaves. Here, 16.8% of customers.
Contract
A file that states what the data must look like: columns, units, ranges and averages. Data that breaks it is rejected.
Gate
A check written in plain code that sits between two steps. If it fails, the pipeline stops. No AI is involved, so it cannot be talked into passing.
Crew and agent
An agent is an AI worker with a role and tools. A crew is a small team of agents that hand work to each other.
PR-AUC
How well the model ranks real churners above customers who stay. 1.0 is perfect; random guessing scores about 0.17 here.
Recall
Of the customers who really left, the share the model flagged in advance.
RAG
Retrieval: before answering, the system searches the company's own documents and quotes the matching sections, so every rule has a source.
Leakage
When the model sees the answer, or a copy of it, while learning. It makes results look better than they are.
