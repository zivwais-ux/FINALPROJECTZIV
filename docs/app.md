# שלב 7: אפליקציית Flask

```bash
uv run web     # http://127.0.0.1:5000
```

האפליקציה מציגה את מה שה-pipeline כבר כתב ב-`artifacts/`, ובודקת קבצי CSV מול החוזה הנעול.
**אין בה LLM ואין בה crewai.** טסט מוודא ש-crewai לא נטען כשמייבאים את האפליקציה.
הקוד נמצא ב-`src/churn_pipeline/web/`: `app.py`, ‏`templates/` ו-`static/style.css`.

| דף | מה מוצג |
|---|---|
| `/` | דף פתיחה למרצה: הסיפור, נתוני ההרצה האחרונה, סיור מודרך של 6 שלבים, תרשים ה-Flow, **טבלת דרישות הקורס ואיפה רואים כל אחת**, והשערים |
| `/architecture` | תרשים SVG של המערכת, עקרונות התכנון, תהליך ה-RAG, וכל 9 הסוכנים עם התפקיד, הכלי והפרומפט. המידע נקרא מקבצי ה-YAML (`artifacts/latest/agents.json`) |
| `/analyst` | נתוני מפתח, טבלת החוזה (עם סימון ליחידות מונחות), דוח האיכות והתובנות של הסוכנים, וקישור לדוח ה-EDA עם הגרפים |
| `/scientist` | שער האיכות, שני המודלים שהושוו, מטריצת הבלבול, ה-permutation importance, כרטיס המודל ודוח ההערכה |
| `/briefings` | תדרוכי השימור משלב 6ג |
| `/runs` | ההרצה האחרונה, וכל תרחישי השבירה עם הדוח והלוג של כל אחד |
| `/checker` | העלאת CSV (עד 10MB), או כפתור לכל תרחיש שבירה. מוצגות ההפרות מול החוזה הנעול והמשתנים החסרים, כמו בשערים |

**עיצוב (סבב שני):**
- מערכת עיצוב אחת ב-`static/style.css`, עם מצב בהיר ומצב כהה (`prefers-color-scheme`), ופונט Inter.
- גרפים ב-CSS ו-SVG, בלי ספריות: שיעורי נטישה לפי פלח, חסרים, השוואת מודלים, מטריצת בלבול, מדי ספים, וטבעות ציון בתדרוכים.
- טקסט שסוכן כתב מסומן "AI-written", כדי שיהיה ברור מה הקוד חישב ומה הסוכנים כתבו.
- בדיקה ב-Playwright: כל הדפים ברוחב 1280 וברוחב 390, וגם במצב כהה. אין גלילה אופקית.

**החלטות:**
- **ממשק באנגלית:** כל התוצרים שהסוכנים כותבים באנגלית.
- **`ARTIFACTS_DIR` ו-`CONTRACT_LOCK`:** משתני סביבה לשינוי הנתיבים, לקראת הפריסה בשלב 8.
- **תרחישי השבירה:** הועברו ל-`src/churn_pipeline/scenarios.py`, ש-`break_it.py` והאפליקציה משתמשים בו. כך האפליקציה לא טוענת את ה-Flow.

**בדיקה:**
- **`tests/test_app.py`, 20 טסטים.** נבדקים:
  - שכל דף נטען
  - שה-checker מעביר את הקובץ הנקי ותופס כל אחד מחמשת התרחישים
  - שקובץ שהועלה נבדק, כולל כתיב חדש ("debit card")
  - שתרחיש לא מוכר נדחה
  - שהאפליקציה לא טוענת crewai
- **צילומי מסך עם Playwright:** בדקתי את כל הדפים ברוחב מחשב וברוחב טלפון (390 פיקסלים), ואין גלילה אופקית.
