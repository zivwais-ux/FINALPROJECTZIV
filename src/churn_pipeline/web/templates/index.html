AI final project · CrewAI flow with a data contract

A churn pipeline that refuses to run on bad data

Two crews of AI agents, a Data Analyst crew and a Data Scientist crew, hand data to each other through a dataset contract checked in code. When the data breaks the contract, the flow stops before modeling and says exactly what changed. An approved churn model and RAG over the company's internal documents then produce a one-page retention briefing per customer.

Why: at Harbor & Vale, an upstream export silently switched a field from cents to dollars. The churn model kept running and ranked customers almost at random for five weeks. This project builds the pipeline that would have caught it.
