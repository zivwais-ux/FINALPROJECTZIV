## החלטות
1. **לא מאחדים קטגוריות.** כל הכתיבים נשארים כפי שהם. הסיבה: שיעורי הנטישה שונים בין הכתיבים,
   כנראה בגלל מערכות מקור שונות, וההחלטה היא לא למחוק את המידע הזה. ההחלטה תתועד בחוזה הנתונים.
2. **לא משלימים ערכים חסרים** ולא מייצרים ערכים סינטטיים. החסרים נשארים NaN ומתועדים ברשימה.
3. **ערכים קיצוניים:** טרם הוחלט.

## השלכות לשלבים הבאים
- **בחוזה הנתונים:** 7 העמודות יסומנו `nullable: true`, עם מספר החסרים הצפוי לכל עמודה. `allowed_values` יכלול את כל הכתיבים המקוריים.
- **המודלים** צריכים לעבוד עם NaN. הבחירה תיסגר בשלב 4.
- **עמודת הכסף לדמו של שבירת יחידות:** `CashbackAmount` (ממוצע 177.22, ללא חסרים). המטבע לא מצוין ב-`Data Dict`.
