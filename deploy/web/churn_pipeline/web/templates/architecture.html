Design principles

Agents decide, tools compute

Every number in an agent's text comes from a Python tool's output. Agents choose, explain and write; they never do arithmetic.

Gates are code

The contract check, the lock comparison and the quality gate are plain Python. No LLM can talk the flow past a broken handoff.

Rules are code

The retention playbook's rules (who is contacted, how, whether an offer is allowed) are applied in code. The briefing agent explains the decisions; it cannot change them.

Fail loudly, explain precisely

A failed gate writes a report naming the column and the change, for example "about 100x off, possible unit change", and exits with 1.

The RAG pipeline

Retrieval over Harbor & Vale's internal documents (src/churn_pipeline/rag.py).

Corpus

7 documents

Retention playbook, discount policy, past campaigns, competitor offers, postmortem, latest insights, model card.

Chunk

One chunk per section

40 sections, each prefixed with "document > section" for context.

Embed

text-embedding-3-small

Cached by the text's SHA-256; only changed sections are embedded again.

Retrieve

Top 4 by cosine

Each hit carries cite_as, so the briefing can cite its source.

Decide

Plan in code

Contact, channel and offer come from the playbook as code; the agent only explains them.

Guardrail

Check the explanations

Every decision explained, none walked back, and only real news links, or the agent tries again.
